# 全屏准星预览版 · Xbox Game Bar

v0.3.0-preview.1 新增独立的 Game Bar 组件，用于保留 CS 视频设置中的“全屏”选项。它通过 Windows 游戏覆盖层显示准星，不再依赖原有 WPF 桌面窗口盖住游戏。

**这是实验支持，不是已完成 CS 实测的正式兼容版。** 当前机器未安装 CS。真正绕过桌面合成的独占呈现、Vulkan、不同显卡驱动及系统设置仍可能影响 Game Bar。请先在 CS 全屏时按 **Win+G**：Game Bar 必须能显示在游戏画面上。若它只会切出游戏，新组件也不能保证显示。

## 安装预览包

需要 Windows 10/11 x64、已安装并可用的 Xbox Game Bar，以及两个下载：

- `Reticle-v0.3.0-preview.1-win-x64.zip`：原有编辑器的预览版。
- `Reticle-GameBar-v0.3.0-preview.1-win-x64.zip`：需要安装的 Game Bar 组件，不能作为普通 EXE 直接运行。

Game Bar 预览包采用测试代码签名，尚未通过 Microsoft Store 分发。安装脚本会核对包名、发布者、签名证书及文件校验值。公开 `.cer` 仅包含公钥，私钥不在下载包中。

解压 Game Bar 包，阅读包内安装说明后运行 `install-gamebar.ps1`。如果 Windows 尚未信任该测试证书，脚本会停止并显示证书指纹及明确的安装步骤。信任测试证书属于本机系统变更，首次安装需要用户自行确认；不要关闭签名验证、安全防护或随意导入到“受信任的根证书颁发机构”。正常使用不需要管理员权限。

## 使用

1. 如果 Win+G 会黑屏或切出游戏：退出 CS，找到 `cs2.exe`，右键“属性 → 兼容性”，取消勾选“禁用全屏优化”，应用后重启游戏。CS 视频设置仍选“全屏”。如果改过“更改所有用户的设置”，也要检查其中的同一选项。再次确认 Win+G 能覆盖游戏；未勾选该选项并不等于系统一定会采用可覆盖的呈现路径。
2. 正常退出旧版编辑器，启动预览版 `Reticle.exe`。
3. 按 **Win+G**，在小组件菜单中打开 **Reticle Studio 准星**。
4. 在组件标题栏点击图钉进行固定，并在 Game Bar 中开启鼠标穿透。退出 Game Bar 后只有准星显示。
5. 编辑器选择 **全屏 · Game Bar（实验）**，点击 **开启全屏组件**。颜色、形状、尺寸与偏移自动同步；`Ctrl+Alt+H` 控制显示 / 隐藏。
6. 在组件中点击“居中”。Game Bar 负责组件所在显示器；多屏时先将组件移到游戏的屏幕，再居中。编辑器的显示器选择仅适用于桌面模式。

游戏过程中可以把编辑器收起到托盘。正常退出编辑器会关闭同步准星；如果编辑器意外退出，组件会在心跳超时后隐藏，不会一直保留失联的准星。

组件也可从前台页面导入已有 JSON 配置，以独立模式使用。该方式不依赖编辑器心跳；需要再次使用实时同步时，先在组件前台页面选择“使用桌面同步”，再从编辑器开启全屏组件。

## 玩家验证清单

请在不影响其他玩家的本地练习环境验证：

- CS 显示模式仍为“全屏”，Game Bar 在游戏上方显示。
- 固定组件并关闭 Game Bar 后，准星仍可见、画面无黑底。
- 移动鼠标、射击和游戏快捷键正常，准星不会捕获点击。
- 三种形状、调色盘、尺寸、透明度和 `Ctrl+Alt+H` 同步正确。
- Alt+Tab 切出再切入、改变游戏分辨率之后仍居中；必要时打开组件重新居中。
- 多屏与不同缩放比例下位置、大小正确。

若仍失败，请记录 Windows 版本、CS 渲染接口、游戏分辨率、屏幕缩放、Game Bar 能否覆盖游戏、是否已固定 / 开启穿透。不要把桌面测试通过当成游戏兼容性保证。

源码附带 `scripts/check-fullscreen.ps1`，可只读检查 Windows / Game Bar 版本和已安装 CS 的兼容性标记。可选参数 `-GameExecutable '完整的cs2.exe路径'` 指定游戏位置，`-OutputPath '新报告文件.json'` 保存到本机。它不修改注册表、不读取游戏内存、不上传报告，也不能仅靠设置值判断实际呈现模式。

## 实现与边界

桌面编辑器把仅包含准星参数和开关的 JSON 写入已安装组件的本地 `LocalState/overlay-state.json`。组件每 250 ms 检查更新，编辑器每 3 秒刷新心跳。参数不上传、不访问网络、不读取游戏内存、不注入游戏进程，也不更改 CS 显示模式。

Game Bar 的固定及鼠标穿透由用户控制。无可靠覆盖通道时，程序不会强行修改游戏窗口或操作系统安全设置。
