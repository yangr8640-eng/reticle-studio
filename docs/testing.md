## v0.3.0-preview.1 · Game Bar 全屏组件

2026-10-26，Windows 11 25H2 / 单屏 1920 × 1080。该版本保持实验状态，目标是用户允许 Windows 全屏优化、CS 菜单继续选择“全屏”的配置。

- WPF Release 构建 0 警告 / 0 错误，16 项核心检查通过，包括状态 schema、UTC 心跳、参数与显式关闭状态的往返。
- 54 项必过桌面诊断通过，另全局快捷键可注册；新增显示后端切换、显示器选择归属、包身份计算、切回后不开启桌面覆盖层检查。最小窗口布局已查看，无按钮裁切。
- 独立 Game Bar 几何模型在 .NET 10 下检查了十字/斜十字径向间距、最大正负偏移的容纳尺寸、不同 DPI 与非有限数值约束。实际 UWP 绘制和 Game Bar 宿主行为仍需安装验证。
- 用临时 `net10.0-windows10.0.19041.0` 工程链接真实组件解析器，使用 Windows.Data.Json 读取 GameBarStateStore 实际输出，22 项协议检查全部通过：三种形状与开关、全部外观字段、UTC 精度、大小限制、schema / 字段类型 / 颜色 / 非有限数值。结果保存在 `artifacts/gamebar-protocol-check/results.json`；未访问应用私有目录或安装组件。
- 安装脚本负面检查确认拒绝越界路径和错误 SHA256；未执行测试证书导入。WinVerifyTrust 对已签名的微软 .NET 程序返回成功，对无签名脚本返回拒绝。
- 首轮 GitHub UWP 编译和 .NET Native 已成功，安装包阶段发现缺少 PhoneIdentity 清单项，随后补齐。第二轮安装前检查拒绝 UWP 6.2.15 上游运行库版本不一致（声明 2.3.60521.0，实际 2.3.60518.0），现固定至已核对 manifest / targets 一致的 6.2.14；最终构建结果以对应 CI 记录为准。
- [最终 Game Bar 构建](https://github.com/yangr8640-eng/reticle-studio/actions/runs/40308311711) 成功，完成 UWP / .NET Native 编译、APPX 打包、签名及依赖校验；同提交的 WPF 构建也成功。下载后已核对全部 9 个包内文件的 SHA256，三个 Microsoft 依赖签名有效，主包签名与公开测试证书匹配。
- 已修复复查发现的瞬时 I/O 失败永久停同步问题：开启状态继续 heartbeat 重试，超过 15 秒无有效心跳时由组件隐藏；UI 不把文件发送成功描述为游戏中已经显示。

- 用户明确授权后已在本机安装指定测试证书及组件，包状态 `Ok`，Game Bar 协议激活后组件进程运行。安装时发现重复部署已满足的运行库会触发 `0x80073D02`，安装器已修复为只安装缺少的框架；未强制关闭其他应用。
- 下载后的便携编辑器通过全部 54 项桌面诊断。实际 UI 切换到 Game Bar 模式后，Ctrl+Alt+H 写入已安装组件的 LocalState，参数与当前外观一致，3 秒心跳正常更新。
- 最终 Game Bar ZIP 使用 CI 产生且已验证的原 APPX / 公共证书，更新安装脚本及对应哈希后重新封装；APPX 二进制未更改，最终包再次通过安装前验证。ZIP SHA256 为 `e31b4e540109bc045911f257eb8031481986ae75ceb9defb6f552b01233e2e8b`，测试证书指纹为 `BB99DCBD62D263A7C7732AF8D29117F26C41754A`。
- 最终源码 `ba516df` 的 [Game Bar 标签构建](https://github.com/yangr8640-eng/reticle-studio/actions/runs/40311213334) 和 [桌面标签构建](https://github.com/yangr8640-eng/reticle-studio/actions/runs/40311213357) 均成功，对应分支构建也成功。公开预览 Release 的五个附件摘要均核对一致。

## v0.2.1 · 无边框全屏遮挡恢复

2026-10-26，Windows x64 / 单屏 1920 × 1080。

- 已先复现旧版缺陷：显示准星后创建铺满屏幕的无边框置顶窗口，准星被压在后面；新增的 `overlayRecoversAboveFullscreenWindow` 在修复前失败，修复后通过。
- Release 构建 0 警告 / 0 错误，15 项核心检查通过。
- 桌面诊断有 50 项必过检查，新增 9 项检查全屏窗口遮挡、自动恢复 z-order、丢失置顶标志及偏移 / 尺寸后的恢复、恢复期间不抢焦点、隐藏后持续隐藏和重新开启后恢复守护。
- 开发版及自包含便携版均通过全部 50 项必过检查。诊断时旧版占用了全局快捷键，`hotkeyAvailable=false` 单独记录为环境状态，没有计入通过项。
- 正常退出旧版后已启动 v0.2.1 便携版，确认快捷键注册警告为空；实际发送 `Ctrl+Alt+H` 两次验证开启 / 关闭，最后保持准星关闭。新版读取原有磁盘配置，未更改外观参数。
- 修复诊断程序的退出模式，避免关闭诊断窗口时提前退出并掩盖失败退出码；脚本同时校验 `passed` 字段，并清理旧报告，防止误报成功。
- 已检查最小窗口渲染，新增的全屏模式提示及按钮没有裁切。
- 自动恢复每 500 ms 执行一次，仅在准星可见时运行；位置和尺寸未变时只恢复 z-order。显示模式 / DPI 消息在 WPF 处理完成后触发位置刷新。
- [GitHub Actions v0.2.1](https://github.com/yangr8640-eng/reticle-studio/actions/runs/40298483128) 及对应分支构建均成功，完成 Windows 构建、核心检查、自包含打包和产物上传。公开 Release 的两个附件摘要均与本地一致。

测试窗口是普通 WPF 无边框窗口，没有 DirectX 交换链。本机 Steam 库未安装 CS，**不能将本次通过的桌面诊断视为 CS 游戏内实测**。独占全屏仍不支持；实际切换显示分辨率、混合 DPI、多屏及其他持续争抢置顶的覆盖层仍待实机验证。
